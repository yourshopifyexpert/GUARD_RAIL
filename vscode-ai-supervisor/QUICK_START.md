# Admin Control System - Quick Start Guide

## 🚀 5-Minute Setup

### 1. Build (30 seconds)
```bash
cd /home/user/GUARD_RAIL/vscode-ai-supervisor
npm run compile
```

### 2. Launch (10 seconds)
Press `F5` in VS Code → Extension Development Host opens

### 3. Test Block Save (1 min)
```javascript
// Create test.js and write:
eval(userInput);

// Press Ctrl+S
// ❌ Result: SAVE BLOCKED!
```

### 4. Test File Lock (1 min)
```
1. Open package.json
2. Ctrl+Shift+P → "AI Supervisor: Lock Active File"
3. Try to save → ❌ BLOCKED!
```

### 5. Test Emergency Stop (30 sec)
```
Press: Ctrl+Shift+Alt+S
// 🛑 Result: Emergency stop activated!
```

## 🎮 Quick Commands

- `Ctrl+Shift+Alt+S` - Emergency Stop
- `Ctrl+Shift+P` → "Admin Panel" - Open Dashboard
- `Ctrl+Shift+P` → "Lock File" - Lock Active File
